# Documentation screenshot input

Place the approved UAT screenshots in this directory using the names listed in
`../ATTENDANCE_AUTOMATION_MANUAL_TESTING.md`. The document generator embeds the
images into the DOCX and PDF; recipients do not need this folder.

Use PNG where possible. JPG, JPEG, and WEBP are also accepted when the base
filename is unchanged. Do not include real personal data or production salary
information.
